# FlashTL-1K Dataset Tools

This directory contains the utilities used for contextual analysis and statistical characterization of the **FlashTL-1K** dataset.

The tools provide an optional analysis pipeline for extracting spatial, temporal, depth, and scene-level information from the videos, followed by dataset-level statistical analysis.

## Files

| File | Description |
|------|-------------|
| `extract_context.py` | Extracts contextual features from FlashTL-1K videos using Grounding DINO, SAM2, Depth Anything V2, FFT analysis, CLIP, and BLIP-2. |
| `dataset_datasheet.py` | Generates dataset composition and descriptive statistics from the extracted contextual metadata. |

---

### Run

From the repository root:

```bash
python dataset_tools/extract_context.py \
    --data_root /path/to/FlashTL-1K \
    --output_dir outputs/context
```

The script automatically uses a CUDA-enabled GPU when available.

### Quick Test

Before processing the complete dataset, the pipeline can be tested on a small subset:

```bash
python dataset_tools/extract_context.py \
    --data_root /path/to/FlashTL-1K \
    --output_dir outputs/context_test \
    --sample 5
```

This processes up to five videos from each class.

### Optional Modules

Individual components can be disabled when they are not required or when computational resources are limited.

For example:

```bash
python dataset_tools/extract_context.py \
    --data_root /path/to/FlashTL-1K \
    --output_dir outputs/context \
    --skip_sam \
    --skip_blip2
```

Available options include:

```text
--skip_gdino
--skip_sam
--skip_depth
--skip_fft
--skip_clip
--skip_blip2
```

The number of sampled frames used by the contextual models can also be changed:

```bash
python dataset_tools/extract_context.py \
    --data_root /path/to/FlashTL-1K \
    --output_dir outputs/context \
    --num_frames 8
```

### Output

The extracted contextual information is saved as:

```text
outputs/context/
├── context_results.xlsx
└── extraction.log
```

`context_results.xlsx` contains two sheets:

- **Context Results** — video-level contextual features
- **Summary Statistics** — dataset-level statistics derived from the extracted features

## Dataset Statistics

`dataset_datasheet.py` summarizes the contextual metadata generated by the extraction pipeline.

It reports the FlashTL-1K class and condition distribution together with descriptive statistics for available contextual attributes, including flashing frequency, flicker ratio, traffic-light size, and relative depth.

### Run

After completing contextual feature extraction:

```bash
python dataset_tools/dataset_datasheet.py \
    --context outputs/context/context_results.xlsx \
    --output outputs/dataset_statistics.xlsx
```

The generated workbook contains:

```text
dataset_statistics.xlsx
├── Composition
└── Descriptive Statistics
```

The **Composition** sheet summarizes the number of flashing red and flashing yellow clips across the five FlashTL-1K conditions:

- Inside-Day
- Inside-Night
- Outside-Day
- Outside-Night
- Rain

The **Descriptive Statistics** sheet summarizes the available temporal and contextual attributes for each class.

---

## Notes

The contextual-analysis pipeline is **not required to train FlashNet**. These utilities are provided for dataset analysis, characterization, and reproducibility of the contextual statistics reported with FlashTL-1K.

Some components, particularly **SAM2** and **BLIP-2**, have additional computational and memory requirements. They can be disabled using the corresponding command-line options when necessary.

For installation requirements and the main FlashNet training/evaluation instructions, please refer to the main repository README.
